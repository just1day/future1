# 🚸 세이프워크 (SafeWalk)

아이가 **걸으면서 스마트폰을 보면 화면을 잠그고**, 특히 **횡단보도 앞에서는 즉시 잠가서**
"폰 보며 길 건너기" 사고를 막는 안드로이드 앱입니다.

## 동작 방식

| 상황 | 결과 |
|---|---|
| 서 있거나 앉아서 폰 사용 | 아무 일도 없음 |
| 걸으면서 폰 사용 (일반 도로) | 5초 유예 후 주황색 잠금 화면 + 진동 |
| 횡단보도 30m 안에서 걸으며 폰 사용 | **즉시** 빨간 잠금 화면 + 강한 진동 |
| (옵션) 횡단보도 앞에서 신호 대기하며 폰 사용 | 즉시 잠금 (GPS 정확도 15m 이내일 때만) |
| 멈춰 서서 3초 지남 / 화면 끔 | 잠금 해제 |
| 버스·자동차 탑승 중 (빠른 속도 + 걸음 없음) | 잠그지 않음 |

- **걷는 중 판단**: 휴대폰 걸음 센서(최근 4초에 4걸음 이상) + GPS 속도(0.6~8 m/s)
- **횡단보도 위치** (두 데이터 중 더 가까운 것을 사용)
  - **공공데이터포털 「전국횡단보도표준데이터」** (주 데이터): 전국 자료를 한 번 받아 휴대폰에 저장, 인터넷 없이도 동작
  - **OpenStreetMap** (보완): 공공데이터에 빠진 곳을 위해 주변 600m를 수시로 받음
- **잠금 화면**: "다른 앱 위에 표시" 권한으로 모든 앱 위를 덮고 터치를 막음
- **긴급전화 112/119 버튼**은 잠금 화면에서도 항상 누를 수 있고, 누르면 2분간 잠금이 멈춤
- **보호자 PIN**: 보호 끄기·설정 변경에 PIN 필요
- 재부팅 후 자동으로 다시 켜짐 (위치 '항상 허용' 필요)

## 프로젝트 구조

```
core/   순수 Kotlin 판단 로직 (안드로이드 없이 단위 테스트 가능)
  Geo.kt              거리 계산, 격자 횡단보도 인덱스, Overpass 쿼리
  PublicCrosswalkData.kt  공공데이터 API 주소·응답 파싱·페이지 다운로드·저장 형식
  WalkingDetector.kt  걸음 센서 + GPS 속도로 "걷는 중" 판단
  SafetyEngine.kt     잠글지/풀지 결정 (유예·해제 시간 포함)
app/    안드로이드 앱 (외부 라이브러리 없음, 프레임워크 API만 사용)
  SafeWalkService.kt     항상 실행되는 보호 서비스 (0.5초마다 판단)
  LockOverlay.kt         전체 화면 잠금 오버레이
  CrosswalkRepository.kt 공공데이터 저장/불러오기 + OSM 보완
  MainActivity.kt        보호자 설정 화면 (권한·PIN·옵션·인증키·테스트)
  BootReceiver.kt        재부팅 시 자동 시작
```

## 공공 횡단보도 데이터 연결

1. [공공데이터포털](https://www.data.go.kr)에 로그인 → 「전국횡단보도표준데이터」 검색 → **오픈API 활용신청** (보통 자동 승인)
2. 마이페이지 → 활용신청 현황에서 **일반 인증키** 복사 (Decoding/Encoding 어느 쪽이든 OK)
   - 승인 직후에는 키가 등록되기까지 1~2시간 걸릴 수 있어요 (`SERVICE_KEY_IS_NOT_REGISTERED` 오류)
3. 키 넣는 방법 (둘 중 하나)
   - 앱에서: **공공데이터포털 인증키 입력** 버튼
   - 빌드 때: 프로젝트 폴더의 `local.properties`에 `DATA_GO_KR_KEY=발급받은키` 한 줄 추가 (git에 올라가지 않음)
4. 앱에서 **전국 횡단보도 데이터 받기** → 1,000개씩 페이지로 받아 저장 (Wi-Fi 권장, 한 번만 하면 됨)

API: `https://api.data.go.kr/openapi/tn_pubr_public_crosswalk_api?serviceKey=…&pageNo=…&numOfRows=1000&type=json`
→ 응답의 `latitude`, `longitude`를 사용합니다.

## 테스트 방법 (휴대폰에서)

앱 아래쪽 **테스트** 영역에서:

1. **📍 지금 위치에서 가장 가까운 횡단보도 찾기** → 공공데이터/OSM 각각의 거리 표시. 실제 횡단보도 앞에 서서 눌러 보세요 (30m 이내면 "횡단보도 앞으로 판정").
2. **🗺 지도에서 보기** → 찾은 횡단보도 위치가 실제와 맞는지 지도 앱으로 확인
3. **🚶 걷는 중으로 가정하기 (5분)** → 걷지 않아도 잠금 화면을 시험할 수 있어요. `보호 시작` 후 켜고, 다른 앱을 열면 5초 뒤(횡단보도 근처면 즉시) 잠김
4. **실시간 상태** → 보호 중일 때 1초마다 걷는 중 / 횡단보도 거리 / 판정이 갱신됨. 실제로 걸으며 확인하세요.

## 설치 파일(APK) 받기 — Android Studio 없이

코드를 올릴 때마다 GitHub Actions가 자동으로 테스트하고 APK를 만듭니다.

1. GitHub 저장소 → **Actions** 탭 → 가장 위의 초록색 ✅ 실행 클릭
2. 아래쪽 **Artifacts**의 `safewalk-debug-apk` 다운로드 → 압축 풀기 → `app-debug.apk`
3. 휴대폰으로 옮겨 설치 (설정에서 "출처를 알 수 없는 앱 설치" 허용 필요)

## 빌드 / 실행

Android Studio(최신)로 폴더를 열고 실행하거나:

```bash
./gradlew :core:test          # 판단 로직 단위 테스트
./gradlew :app:assembleDebug  # APK 생성 → app/build/outputs/apk/debug/
```

설치 후 앱에서 ①②③ 권한을 차례로 허용 → 보호자 PIN 설정 → **보호 시작**.

- 최소 Android 8.0 (API 26), 타깃 Android 15 (API 35)

## 한계와 다음 단계

- **iOS는 이 방식이 불가능**합니다. iOS는 다른 앱 위에 화면을 덮을 수 없어서, Apple의 Screen Time(FamilyControls) API와 별도 승인이 필요합니다.
- 공공데이터는 지자체가 등록한 만큼만 있어서 지역별로 빠진 곳이 있을 수 있어요 (그래서 OSM으로 보완).
- Overpass 공용 서버는 시범용입니다. 실제 서비스는 자체 서버나 캐시가 필요합니다.
- 아이가 앱을 삭제하거나 강제 종료하는 것은 막지 못합니다 → Google Family Link와 함께 쓰거나, 기기 관리자(Device Admin) 기능 추가를 검토하세요.
- 보호자 앱(아이 위치 보기, "횡단보도에서 폰 사용 N회" 알림 등)은 아직 없습니다.
- 실제 기기에서 GPS·걸음 센서 민감도 튜닝이 필요합니다 (`SafeWalkConfig`, `WalkingDetector` 기본값).
